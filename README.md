# TXT 轉 EPUB 工具（前端 SPA）

[English](README-en.md)

一個純前端的 TXT 小說轉 EPUB 小工具。支援繁體中文、簡體中文與英文文本，自動識別章節並產生含目錄的 EPUB 檔案，全部處理都在瀏覽器本機完成，不上傳檔案，保護使用者隱私。

線上體驗網址：https://txt2epub.bluice.xyz/

## 功能特色

- 前端單頁應用（SPA），靜態部署即可使用
- 透過瀏覽器 File API 讀取本機 TXT 檔案
- 自動偵測文字編碼（使用 `jschardet`），支援 UTF-8 / GB18030 / Big5 等常見編碼
- 章節識別規則：
  - 刪除每行前導空白（半形/全形）
  - 行首比對「第 x 章」作為章節標題，其中 x 可為阿拉伯數字或中文數字
  - 兩個「第 x 章」之間的內容視為該章節正文
  - 檔案開頭到第一章之間的非空內容會作為「簡介」章節
- 簡單的章節預覽與編輯：
  - 預覽章節標題、字數、行數
  - 修改章節標題
  - 將某一章節與上一章節合併

## 技術棧

- 框架：Vue 3（Composition API）
- 語言：TypeScript
- 建置工具：Vite

## 開發與執行

1. 安裝套件：

```bash
npm install
```

2. 啟動開發伺服器：

```bash
npm run dev
```

然後在瀏覽器中造訪終端機輸出提示的本機網址（通常是 `http://localhost:5173`）。

3. 建置正式版本：

```bash
npm run build
```

建置輸出位於 `dist/` 目錄，可部署到任意靜態託管服務（如 GitHub Pages、Vercel、Cloudflare Pages 等）。

## 測試

- 測試框架： [Vitest](https://vitest.dev/)
- 執行全部測試（單元 + 整合，一次性執行）：

```bash
npm test -- --run
```

整合測試使用的 TXT 測試檔案存放在 `tests/fixtures/` 目錄下。

## 章節識別規則說明

1. **刪除行首空白**：對每一行，刪除行首的所有空白字元（空格、Tab、全形空格等）。
2. **章節標題識別**：
   - 行首比對：`第 + 數字/中文數字 + 章`；
   - 數字可以是：
     - 阿拉伯數字：`0-9`；
     - 中文數字：`零一二三四五六七八九十百千萬兩〇○` 等；
   - 標題後面可以接任意文字，例如：`第一章 重逢`、`第12章 序幕`。
3. **正文劃分**：
   - 偵測到的相鄰兩條「第 x 章」之間的內容視為前一章節的正文；
   - 最後一章的正文一路延伸到文本結尾；
   - 檔案開頭到第一章之前的非空內容自動作為「簡介」章節。
4. **兜底策略**：
   - 如果完全沒有識別到「第 x 章」行，則預設將全文視為一個章節（標題為「正文」/「Content」）。
